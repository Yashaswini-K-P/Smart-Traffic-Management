# TrafficIQ – Smart Traffic Management System

A machine learning-based web application for traffic volume prediction and historical traffic analysis.

TrafficIQ uses historical traffic data and a trained Random Forest model to predict traffic volume based on date, time, and weather conditions. It also provides interactive dashboards and visualizations to explore historical traffic patterns.

## 1. Features

TrafficIQ consists of four main modules:

### Overview Dashboard
- Displays average, maximum, and minimum traffic volume.
- Provides an overview of historical traffic statistics.

### Traffic Prediction
- Predicts traffic volume using date, time, and weather inputs.
- Classifies predicted traffic into Low, Moderate, or Heavy congestion.

### Historical Analytics
- Visualizes average traffic by hour, weekday, and month.
- Displays the distribution of congestion levels.

### Model Performance
- Compares Decision Tree and Random Forest models.
- Displays MAE, RMSE, and R² evaluation metrics.
- Uses the Random Forest model for predictions.

> **Note:** TrafficIQ uses a historical dataset. It does not retrieve live traffic information from Google Maps or traffic sensors. Predictions are generated by the trained model using the inputs provided by the user.

## 4. Getting Started

You can run TrafficIQ using either Docker or a local Python and Node.js environment.

### Method 1: Using Docker (Recommended)

**Prerequisite:** Install [Docker Desktop](https://www.docker.com/products/docker-desktop/) and ensure Docker Engine is running.

**Step 1: Clone the repository**

```bash
git clone https://github.com/Yashaswini-K-P/Smart-Traffic-Management.git
cd Smart-Traffic-Management
```

**Step 2: Build and start the application**

```bash
docker compose up --build
```

Docker automatically:
- Builds the frontend and backend containers.
- Installs the required dependencies.
- Starts the FastAPI backend and React frontend.
- Downloads the trained model if it is not already available.

The first startup may take longer because dependencies and the model need to be downloaded.

**Step 3: Open the application**

| Service | URL |
|---|---|
| TrafficIQ | http://localhost:5173 |
| Backend API | http://localhost:8000 |
| API Documentation | http://localhost:8000/docs |

To stop the application:

```bash
docker compose down
```

The downloaded model is stored in a Docker volume and is preserved when using the command above. Avoid `docker compose down -v` unless you intentionally want to delete that volume.

---

### Method 2: Without Docker

**Prerequisites**

Install the following:

- [Python 3.12](https://www.python.org/downloads/)
- [Node.js 22 LTS](https://nodejs.org/)
- [Git](https://git-scm.com/downloads)

**Step 1: Clone the repository**

```bash
git clone https://github.com/Yashaswini-K-P/Smart-Traffic-Management.git
cd Smart-Traffic-Management
```

**Step 2: Start the backend**

On Windows, open Command Prompt from the project root and execute the following command:

```cmd
if not exist "backend\venv\Scripts\python.exe" py -3.12 -m venv backend\venv && call backend\venv\Scripts\activate.bat && python -m pip install --upgrade pip && python -m pip install -r backend\requirements.txt && cd backend && python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

This command creates the virtual environment, installs dependencies, and starts the backend. The trained model is downloaded automatically if required.

Keep this terminal running.

**Step 3: Start the frontend**

Open a second Command Prompt window:

```cmd
cd /d path\to\Smart-Traffic-Management\frontend
npm ci
npm run dev
```

Replace `path\to\Smart-Traffic-Management` with the actual project directory.

**Step 4: Open the application**

Visit:

http://localhost:5173

Keep both the backend and frontend terminals running while using the application.

## 5. API Endpoints

The FastAPI backend provides the following endpoints:

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | API status |
| GET | `/health` | Backend health check |
| POST | `/predict` | Predicts traffic volume |
| GET | `/analytics` | Retrieves historical traffic analytics |

Interactive API documentation is available at:

http://localhost:8000/docs

### Example Prediction Request

**Endpoint:** `POST /predict`

```json
{
  "date": "2026-11-16",
  "hour": 8,
  "temp_c": 25,
  "rain_1h": 0,
  "snow_1h": 0,
  "clouds_all": 40
}
```

The API returns the predicted traffic volume and its corresponding congestion level.

## 6. Important Notes

- Use Python 3.12 for manual backend setup to maintain compatibility with the trained model.
- Install backend dependencies using `backend/requirements.txt`.
- Use `npm ci` to install frontend dependencies consistently.
- An internet connection is required for the initial model download.
- Ensure the Google Drive model file is accessible if automatic downloading fails.
- The application uses historical traffic data and does not currently support live traffic monitoring.
